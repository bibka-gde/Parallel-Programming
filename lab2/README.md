# Лабораторная работа №2: Параллельное умножение матриц с OpenMP

## Цель работы
Модифицировать программу умножения матриц для параллельной работы с использованием технологии OpenMP и провести серию экспериментов.

## Описание программы

### Алгоритм
Используется стандартный алгоритм умножения матриц C = A × B:
- C[i][j] = Σ(A[i][k] × B[k][j]), где k = 0...n-1

### Параллелизация
Параллелизация выполнена по внешнему циклу (по строкам результирующей матрицы):
```cpp
#pragma omp parallel for schedule(dynamic)
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // вычисления
    }
}
```

### Анализ результатов

**Наблюдения:**

1. **Малые матрицы (200×200):** Ускорение растёт почти линейно до 4.64× при 8 потоках. 
   Накладные расходы OpenMP минимальны из-за малого объёма данных.

2. **Средние матрицы (400×400 – 1200×1200):** Достигается максимальное ускорение 
   6.29× – 6.55× при 8 потоках. Это близко к теоретическому максимуму для 8 ядер.

3. **Большие матрицы (1600×1600 – 2000×2000):** Ускорение снижается до 4.23× при 8 потоках.
   Причина: ограничение пропускной способности памяти (memory bandwidth bound).
   При больших размерах матрицы основное время тратится на чтение/запись данных,
   а не на вычисления.

4. **Аномалия при 2000×2000:** Время для 1 потока (11.66 сек) почти равно времени 
   для 1600×1600 (10.72 сек), что указывает на влияние кэш-памяти и виртуальной памяти.

**Вывод:** Оптимальное количество потоков зависит от размера задачи. 
Для матриц 800×800 – 1600×1600 рекомендуется использовать 8 потоков.
