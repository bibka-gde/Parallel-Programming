# Умножение квадратных матриц на C++

## 1. Постановка задачи
Реализовать умножение двух квадратных матриц на C++, измерить время и объём используемой памяти, а также исследовать параллельную версию с использованием OpenMP.

## 2. Алгоритм
Базовая формула: `C[i][j] = Σ A[i][k] * B[k][j]`, вычислительная сложность O(N³).
Оптимизация: использован порядок циклов `i-k-j` вместо классического `i-j-k`. Это обеспечивает последовательное чтение строк матрицы B, улучшая локальность данных в кэше процессора и давая прирост производительности на больших размерах.

## 3. Верификация
Результат умножения сравнивается с эталонным результатом, полученным через библиотеку NumPy (Python). 
Максимальная допустимая погрешность: < 1e-3 (из-за особенностей арифметики с плавающей точкой).
Скрипт верификации: `Verify.py`. Результат: Верификация пройдена.

## 4. Результаты экспериментов
Зависимость времени выполнения (в секундах) от размера матрицы (N) и числа потоков (T):

| N (Размер) | 1 поток | 2 потока | 4 потока | 8 потоков |
| :--- | :--- | :--- | :--- | :--- |
| **128** | 0.001 | 0.0012 | 0.001 | 0.001 |
| **256** | 0.0083 | 0.0085 | 0.0089 | 0.0086 |
| **512** | 0.0686 | 0.0667 | 0.0665 | 0.0675 |
| **1024**| 0.6585 | 0.6157 | 0.5436 | 0.5572 |
| **2048**| 5.8668 | 6.0865 | 5.7538 | 5.7594 |


## 5. Анализ зависимости
1. **От объёма задачи (N):** При увеличении N в 2 раза, время выполнения возрастает примерно в 8-9 раз (например, с 0.001 до 0.0083 при N=128 и N=256 на 1 потоке). Это полностью подтверждает теоретическую вычислительную сложность алгоритма O(N³).
2. **От параметров распараллеливания (T):** При фиксированном большом N (например, 2048) увеличение числа потоков с 1 до 2 лишь замедляет процесс из-за накладных расходов на создание потоков и синхронизацию (закон Амдала). Но при использовании 4 потоков заметно небольшое ускорение.

## 6. Выводы
- Алгоритм реализован корректно, что подтверждено автоматизированной верификацией.
- Оптимизация порядка циклов и использование OpenMP позволяют эффективно задействовать многоядерные процессоры при решении трудоемких задач.
- Параллелизация наиболее эффективна на больших объёмах данных (N ≥ 512), где вычислительная работа значительно превышает накладные расходы на управление потоками.
