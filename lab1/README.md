# Умножение квадратных матриц на C++

## 1. Постановка задачи
Реализовать умножение двух квадратных матриц на C++, измерить время выполнения и объём используемой памяти.

## 2. Алгоритм
Базовая формула: `C[i][j] = Σ A[i][k] * B[k][j]`, вычислительная сложность O(N³).
Оптимизация: использован порядок циклов `i-k-j` вместо классического `i-j-k`. Это обеспечивает последовательное чтение строк матрицы B, улучшая локальность данных в кэше процессора и давая прирост производительности на больших размерах.

## 3. Сборка и запуск

### Требования
- Visual Studio 2019/2022 с компонентом "Desktop development with C++"
- Python 3.x с библиотекой NumPy (`pip install numpy`)

### Компиляция
1. Откройте `MatrixMultiplication.slnx` в Visual Studio
2. Выберите конфигурацию **Release** и платформу **x64**
3. Build → Rebuild Solution (Ctrl+Shift+B)

### Запуск
```powershell
# Генерация входных данных (матрица 512×512)
.\x64\Release\GenerateInput.exe 512

# Последовательное умножение
.\x64\Release\MatrixMultiplication.exe

# Верификация результата
py Verify.py

## 7. Анализ зависимости времени от объёма задачи

При увеличении размера матрицы N в 2 раза, время выполнения возрастает в среднем в 8.5 раз:

- N=100 → N=200: 0.0007 → 0.0039 (×5.5)
- N=500 → N=1000: 0.0644 → 0.5242 (×8.1)
- N=1000 → N=2000: 0.5242 → 6.3065 (×12)

Это полностью подтверждает теоретическую вычислительную сложность алгоритма **O(N³)**.
